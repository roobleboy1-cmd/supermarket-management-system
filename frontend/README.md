# Single Supermarket Management System — Frontend

A modern, enterprise-grade, high-performance Single Supermarket Management System frontend built with **React.js**, **Vite**, **TypeScript**, **Tailwind CSS**, **TanStack Query**, **Zustand**, and **IndexedDB**.

---

## 🚀 Quick Start Guide

### 1. Requirements
- Node.js (v18+ or v20+)
- npm (v9+)

### 2. Run the Frontend
```bash
# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

The application will be accessible at: **`http://localhost:5173`**

### 3. Production Build
```bash
npm run build
npm run preview
```

---

## 🛠️ Technology Stack

- **React 19 & TypeScript**: Strict type safety & modern component architecture
- **Vite 8**: Ultra-fast HMR and bundle compilation
- **Tailwind CSS v4**: Blue, white, black, and dark navy theme
- **TanStack Query (v5)**: Caching & data synchronization
- **Zustand**: Fast state management (POS cart, theme, auth, offline sync)
- **React Router DOM (v7)**: Client-side routing for all 20 modules
- **IndexedDB (`idb`)**: Robust offline POS transaction queue with UUID idempotency keys
- **Recharts**: Dynamic revenue telemetry & payment breakdowns
- **JsBarcode**: Thermal barcode label printing
